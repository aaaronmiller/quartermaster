## Accepted

- Organize physical library links by provenance source; represent lifecycle,
  function, domain, composition role, cost, trust, and quality as metadata views.
- Keep canonical skill bytes in their Git/user-owned sources.
- Catalog the specialist library without activating it.
- Require an active loadout on this machine before any deployment plan can be
  applied.
- Use starter pipeline forms for code audit, full development, advertising,
  research, and release; keep model-generated proposals advisory.
- Use explicit and pipeline-derived relationships to suggest skills commonly
  used together.
- Do not adopt the current deployed target state as the new baseline.
